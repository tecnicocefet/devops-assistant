# Padrão de nomes de arquivos da base de conhecimento

## Regras

1. Usar apenas letras minúsculas
2. Usar hífen (-) no lugar de espaço
3. Não usar acentos
4. Nome curto e descritivo

## Exemplos

alb-vs-nlb.md  
docker-volume-vs-bind-mount.md  
kubernetes-pod-vs-deployment.md  
terraform-remote-state.md  

## Objetivo

Manter a base de conhecimento organizada e fácil de pesquisar.
