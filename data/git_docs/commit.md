Comando: git commit

O que faz:
Registra mudanças no histórico do repositório Git.

Explicação simples:
Depois de adicionar arquivos com "git add", o comando "git commit"
cria um ponto no histórico do projeto com uma mensagem explicando
o que foi alterado.

Exemplo:

git add arquivo.txt
git commit -m "Adiciona arquivo inicial"

Casos de uso:
- registrar mudanças no código
- criar histórico de desenvolvimento
- permitir rollback para versões anteriores
