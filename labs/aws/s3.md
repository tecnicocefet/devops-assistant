# LAB: AWS S3 - Serviço Simple Storage Service (S3)

## LAB BÁSICO
### Objetivo
Este laboratório tem como objetivo ensinar a criar um bucket no serviço Amazon S3 e carregar arquivos nele.

### Pré-requisitos
Para este lab, você precisa de uma conta AWS ativa com permissões para criar buckets e fazer uploads de arquivos.

### Cenário
Você está conectado ao console da AWS (https://console.aws.amazon.com/).

### Passos
1. No menu principal, clique em "Serviços" e procure por S3.
2. Na página de serviço S3, clique no botão "Criar Bucket".
3. Insira um nome para o seu bucket (por exemplo: meu-primeiro-bucket).
4. Selecione uma região geográfica onde você deseja armazenar os objetos do S3 (você pode escolher a que estiver mais próxima de você para reduzir o tempo de download).
5. Escolha um modelo de preço ou padrão de conformidade. Vamos deixar tudo como está e clique em "Criar".
6. Clique no nome do seu bucket recém-criado para acessá-lo.
7. Agora você pode carregar arquivos nele, basta clicar em "Upload" e selecionar os arquivos que deseja enviar.
8. Depois de selecionados, clique em "Next", defina as permissões do objeto (você pode deixar tudo como está) e clique em "Next".
9. Por fim, clique em "Upload" para iniciar o processo de upload dos arquivos ao seu bucket S3.

### Desafio extra
Experimente criar um novo bucket e carregue uma imagem ou documento para ela. Em seguida, tente baixá-la novamente para verificar se o processo de upload e download está funcionando corretamente.

### Resultado esperado
Você terá criado um bucket no S3 e carregado alguns arquivos nele com sucesso. Você também poderá baixar os arquivos novamente para verificar se o processo de upload e download está funcionando corretamente.

## LAB INTERMEDIÁRIO
### Objetivo
Neste laboratório, você aprenderá a configurar um bucket S3 para servir conteúdo estático web e acessível publicamente na internet.

### Pré-requisitos
Você deve ter um bucket existente no AWS S3 com alguns arquivos carregados nele.

### Cenário
Você está conectado à console da AWS (https://console.aws.amazon.com/) e tem acesso ao seu bucket criado anteriormente.

### Passos
1. No menu principal, clique em "Serviços" e procure por S3.
2. Na página de serviço S3, localize o nome do seu bucket na lista e clique nele para acessá-lo.
3. Clique no botão "Propriedades" e então em "Permissões".
4. Em "Público", marque a opção "Lista" para que qualquer pessoa possa visualizar os objetos neste bucket.
5. Agora, clique no botão "Editar" junto à propriedade "Server Access Logging". Marque a caixa de seleção e escolha o destino do log (você também pode deixar tudo como está). Clique em "Salvar".
6. Agora, clique no botão "Propriedades" novamente e então em "Estatísticas". Marque a caixa de seleção para "Ativar estatísticas de servidor de bloco". Clique em "Salvar".
7. Volte à página do seu bucket e clique na guia "Público" (antes chamada de propriedades). Aqui você pode definir o método de acesso para os objetos neste bucket como "Website Endpoint", escolha um arquivo index (por exemplo, index.html) e um erro (404.html), caso eles não existam. Clique em "Salvar".
8. Agora você deve ter uma URL para acessar o site estático do seu bucket S3. Copie-a e cole no navegador para visualizá-lo.

### Desafio extra
Experimente fazer upload de um arquivo HTML simples (por exemplo, index.html) para o seu bucket e configure-o como página inicial do site. Teste acessar a URL do seu site novamente para verificar se ele agora está funcionando corretamente.

### Resultado esperado
Você terá configurado um bucket S3 para servir conteúdo web estático e público com sucesso. Você também poderá visualizar o site em seu navegador através da URL fornecida pela AWS.

## LAB AVANÇADO
### Objetivo
Neste laboratório avançado, você aprenderá a configurar um bucket S3 para servir conteúdo estático com o CloudFront e SSL (HTTPS).

### Pré-requisitos
Você deve ter um bucket existente no AWS S3 com alguns arquivos carregados nele. Você também precisa de uma chave pública SSH para acessar o servidor onde você hospedará seu site estático.

### Cenário
Você está conectado à console da AWS (https://console.aws.amazon.com/) e tem acesso ao seu bucket criado anteriormente. Você também tem um servidor SSH disponível para hospedar o site estático.

### Passos
1. No menu principal, clique em "Serviços" e procure por S3.
2. Na página de serviço S3, localize o nome do seu bucket na lista e clique nele para acessá-lo.
3. Clique no botão "Propriedades" e então em "Permissões".
4. Em "Público", marque a opção "Lista" para que qualquer pessoa possa visualizar os objetos neste bucket.
5. Agora, clique no botão "Editar" junto à propriedade "Server Access Logging". Marque a caixa de seleção e escolha o destino do log (você também pode deixar tudo como está). Clique em "Salvar".
6. Agora, clique no botão "Propriedades" novamente e então em "Estatísticas". Marque a caixa de seleção para "Ativar estatísticas de servidor de bloco". Clique em "Salvar".
7. Volte à página do seu bucket e clique na guia "Público" (antes chamada de propriedades). Aqui você pode definir o método de acesso para os objetos neste bucket como "Website Endpoint", escolha um arquivo index (por exemplo, index.html) e um erro (404.html), caso eles não existam. Clique em "Salvar".
8. Agora você deve ter uma URL para acessar o site estático do seu bucket S3. Copie-a e cole no navegador para visualizá-lo.
9. No menu principal, clique em "Serviços" e procure por CloudFront. Crie um novo distribuição com base no seu bucket S3 como origem.
10. Depois de criada a distribuição, copie o nome do domínio da sua distribuição (CloudFront).
11. No servidor SSH, instale um certificado SSL para esse domínio. Você pode usar ferramentas como Let's Encrypt ou Certbot para isso.
12. Configure seu servidor web para redirecionar todas as solicitações HTTP para HTTPS e apontá-lo para o CloudFront distribuição usando a URL do domínio da sua distribuição.
13. Agora você deve ter um site estático hospedado no AWS S3 com SSL ativo. Acesse-o em seu navegador e verifique se o conteúdo é exibido corretamente e as solicitações são feitas por HTTPS.

### Desafio extra
Experimente fazer upload de um arquivo HTML simples (por exemplo, index.html) para o seu bucket S3 e configure-o como página inicial do site. Teste acessar a URL do seu site CloudFront com SSL para verificar se ele agora está funcionando corretamente.

### Resultado esperado
Você terá configurado um bucket S3 para servir conteúdo web estático e público com o CloudFront e SSL (HTTPS) com sucesso. Você também poderá visualizar o site em seu navegador através da URL do CloudFront com HTTPS.
