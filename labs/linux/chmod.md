# LAB: Linux - chmod

## LAB BÁSICO
### Objetivo
Este lab tem como objetivo ensinar a utilização do comando `chmod` no linux.

### Pré-requisitos
Um sistema operacional Linux instalado e configurado. Uma conta de usuário com privilégios de administrador (root).

### Cenário
Você tem um arquivo chamado `teste.txt` que está localizado no seu diretório home.

### Passos
1. Abra o terminal e navegue até o diretório onde se encontra o arquivo `teste.txt`.
2. Utilize o comando `ls -l teste.txt` para verificar as permissões do arquivo.
3. Altere a permissão de leitura e execução para todos os usuários utilizando o comando `chmod a+rx teste.txt`.
4. Utilize novamente o comando `ls -l teste.txt` para verificar as novas permissões do arquivo.

### Desafio extra
Altere a permissão de escrita para todos os usuários utilizando o comando `chmod a+w teste.txt` e confirme com o comando `ls -l teste.txt`.

### Resultado esperado
Após seguir os passos, você deve ter alterado as permissões do arquivo para que todos tenham permissão de leitura e execução. Se você tiver concluído o desafio extra, todos também deverão ter permissão de escrita no arquivo.
